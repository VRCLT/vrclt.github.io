Before the first conversation

Three things to get ready.

Read the setup guide ↗

  1. Get VRCLT

    Download the Windows executable from GitHub Releases and run it. Python is not needed for the packaged app.

    Open downloads ↗

  2. Add an API key

    Choose a translation engine, create a key with its provider, and enter it in Settings. Provider usage is billed separately.

    See the engines ↓

  3. Connect your audio

    Install VB-Cable. Send the translated voice to CABLE Input and select CABLE Output as the microphone in your target app.

A few useful answers.

Is VRCLT free?+

The app is open source under the MIT license. Translation uses your own provider API key, and that provider may charge for usage. Check its rates and balance before starting.

Do I need a VR headset?+

No. You can use voice translation and desktop subtitles on Windows without a headset. SteamVR is needed for the VR overlays and wrist menu.

Where does my audio go?+

The app sends audio to the translation provider you select. Your API key and settings are saved locally on your PC. Read the selected provider's data policies before use.

Can I download v1.0 yet?+

Not yet. This page previews v1.0. The download buttons open the latest published GitHub release; the new setup check and updated branding will arrive with v1.0.
