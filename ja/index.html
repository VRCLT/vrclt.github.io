音声翻訳

VRCLT 2.0 は、マイクの翻訳と相手の字幕をひとつの画面で使える Windows アプリです。VRChat と Discord に対応しています。

Windows版をダウンロード

Windows x64 / 翻訳サービスの API キー

話した内容を別の言語に翻訳します。

マイクで話すと、翻訳された音声がVRChatやDiscordに届きます。相手に聞こえる言語を選べます。

相手の話を翻訳字幕で読めます。

相手の話を、選んだ言語の字幕で読めます。アプリ、デスクトップ、SteamVR内に表示できます。

VR内で設定を変更できます。

手首メニューで言語を切り替え、SteamVRダッシュボードで設定を調整。VRChatのチャットボックスにも翻訳を送れます。

デスクトップとVRの操作画面

PC の通訳コンソール、手首メニュー、SteamVR ダッシュボード。字幕は会話例です。

はじめる前に

設定ガイドを読む ↗

  1. VRCLTをダウンロード

    Windows x64 用の EXE をダウンロードして起動します。ZIP にも同じアプリが入っています。

    ダウンロードへ ↗

  2. APIキーを入力

    翻訳エンジンを選び、提供元でAPIキーを取得して設定画面に入力します。サービスの利用料金は別途かかります。

    翻訳エンジンを見る ↓

  3. 音声を接続

    テキストと字幕には VB-CABLE は不要です。翻訳音声を送る場合は出力を CABLE Input、通話アプリのマイクを CABLE Output に設定します。

    VB-Cable ↗

対応する翻訳エンジン

話者を区別する会話には Soniox、無料枠で始めるには Gemini 3.5 Live Translate がおすすめです。Qwen と GPT にも対応しています。利用条件は各サービスでご確認ください。

知っておきたいこと

無料で使えますか？+

アプリはMITライセンスのオープンソースです。翻訳には自分のAPIキーを使用し、提供元によって利用料金が発生します。開始前に料金と残高を確認してください。

VRヘッドセットは必要ですか？+

いいえ。Windows PCだけで音声翻訳とデスクトップ字幕を利用できます。VR字幕や手首メニューにはSteamVRが必要です。

音声とAPIキーはどこへ送られますか？+

音声は選択した翻訳サービスに送信されます。APIキーとアプリの設定はPCに保存されます。利用前に提供元のデータ取り扱い方針を確認してください。
