VOICE TRANSLATION / LIVE SUBTITLES

v1.0 準備中

你的聲音，
另一種語言。

為 VRChat 和 Discord 提供即時語音翻譯與字幕。透過 Windows 應用程式，將麥克風的聲音轉換為選定的語言。

下載 Windows 版 如何開始 ↓

Windows · 自備 API 金鑰 · 語音輸出需要 VB-Cable

你的聲音 → 對方的語言

就像是自己學會了另一種語言

對著麥克風說話，翻譯後的語音就會傳入 VRChat 或 Discord。你可以選擇對方的語言。

對方的語言 → 你的字幕

即時翻譯對方的語言。

將對方的話轉換為選定語言的字幕。在應用程式、桌面或 SteamVR 中都能查看。

VRChat / SteamVR

在 VR 中操作。

透過手腕選單切換語言，在 SteamVR 面板中調整設定，也能將翻譯傳送至 VRChat 聊天框。

Setup / Windows

開始之前。

閱讀設定指南（簡體中文） ↗

  1. 下載 VRCLT

    從 GitHub Releases 下載 Windows 執行檔並開啟。發行版無須安裝 Python。

    前往下載 ↗

  2. 輸入 API 金鑰

    選擇翻譯引擎，向對應服務取得 API 金鑰，並填入應用程式設定。服務使用費用另計。

    查看翻譯引擎 ↓

  3. 連接音訊

    安裝 VB-Cable。將翻譯語音輸出設為 CABLE Input，並將目標應用程式的麥克風設為 CABLE Output。

    VB-Cable ↗

v1.0 將加入設定檢查。 檢查缺少的設定、尋找麥克風，並透過自動設定連接 VRChat 音訊和 OSC。

使用須知。

免費嗎？+

應用程式採用 MIT 開源授權。翻譯使用你自己的 API 金鑰，服務提供者可能依使用量收費。請在開始前確認費率與餘額。

一定需要 VR 頭戴裝置嗎？+

不需要。僅使用 Windows PC 就能進行語音翻譯並查看桌面字幕。VR 字幕和手腕選單需要 SteamVR。

音訊和 API 金鑰會傳送到哪裡？+

音訊會傳送至你選擇的翻譯服務。API 金鑰和應用程式設定儲存在本機。使用前請了解對應服務的資料處理政策。
